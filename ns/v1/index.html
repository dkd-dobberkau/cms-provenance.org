Content Provenance Specification · Draft 0.3

Vocabulary v1

Fields that schema.org does not cover live in this small extension vocabulary. Use it next to schema.org in the JSON-LD context of a Provenance Record:

https://cms-provenance.org/ns/v1

Requests that accept application/ld+json receive the machine-readable JSON-LD context. This page is the human-readable form. The vocabulary is a working draft and follows the specification; terms may still change before version 1.0.

Terms

lastSubstantiveRevisionxsd:dateTime · Layer 1
Timestamp of the last substantive revision of a Document, distinct from any technical save or republish.
maintainedDatexsd:dateTime · Layer 1, optional
Date the content was last confirmed as still accurate. Adopted from the MX vocabulary. A confirmation without an edit updates this field only, never lastSubstantiveRevision.
accessDatexsd:date · Layer 1
Date on which a cited source was accessed.
cpsConformancexsd:integer, 1–4
Conformance level a site claims: 1 Discoverable, 2 Provenance, 3 Verifiable, 4 Citable. Formerly conformanceLevel; kept separate from MX mxCompliance.
generatortext
Name and version of the CMS that produced the Record. Not the same as MX provenanceOrigin, which states how the content was created (human-directed, AI-assisted or automated); consumers must not treat the two as equivalent.
specVersiontext · Layer 4
Version of the specification an Audit Endpoint implements.
contentHashtext · Layer 2
sha256: followed by the hex SHA-256 of the canonical text of the Document (Annex A.3).
signatureobject · Layer 2
Signature over the canonical Record, which includes contentHash (Annex A.5). Holds algorithm, keyId and signatureValue.
algorithmtext · Layer 2
Signature algorithm: Ed25519 or RSA-PSS-SHA256.
signatureValuetext · Layer 2
The signature bytes, base64url-encoded without padding.
keyIdtext · Layer 2
Identifier of the Site Key used for a signature. Enables key rotation; historical keys stay available.
keyURL · Layer 2
Stable URL of the key document holding the public part of the Site Key.
claimlist · Layer 3
The Facts of the Document, each of type Claim with @id {Document URL}#fact-{id} and the quoted text (Section 3.3).
subjectURI · Layer 3
What a Fact is about.
predicateURI · Layer 3
The property a Fact states; a bare term is read as a schema.org term.
objecttext or URI · Layer 3
The value a Fact states: a string, or {"@id": URI}.
evidenceURI · Layer 3, optional
A source supporting the Fact.
confidencetext · Layer 3, optional
measured, estimated or asserted.
validUntilxsd:date · Layer 3, optional
Last day the Fact is valid. The start uses schema.org validFrom.

Example

{
  "@context": ["https://schema.org", "https://cms-provenance.org/ns/v1"],
  "@type": "Article",
  "datePublished": "2026-05-14T09:00:00Z",
  "lastSubstantiveRevision": "2026-05-14T09:00:00Z",
  "maintainedDate": "2026-11-13T10:00:00Z",
  "cpsConformance": 2,
  "generator": "TYPO3 14.0 + provenance 0.1"
}
